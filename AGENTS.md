# AGENTS.md — Legal Agent Installer

## Роль агента

Ты — разработчик установщика для юридического AI-агента на базе OpenCode.
Твоя задача — написать bash-скрипт (и PowerShell-обёртку для Windows),
который разворачивает готового к работе агента-юриста «из коробки».

Пользователь — **не разработчик**. Он должен запустить одну команду,
вставить ключ DeepSeek и начать работать.

## Целевая архитектура

Установщик разворачивает:

1. **OpenCode** — CLI-агент (основа)
2. **DeepSeek API** — LLM (ключ вводит пользователь)
3. **Skills** — `source-locked-ru` (дисциплина: только по источникам)
4. **MCP-серверы**:
   - `ru-legal-mcp` — законы РФ + kad.arbitr (через `uvx`)
   - `office-docs-mcp` — чтение/запись Word/Excel (через `uvx`)
   - `sudrf-scraper-mcp` — **кастомный**, обёртка над sudrfscraper
5. **sudrfscraper** — JAR-приложение для сбора судебной практики
6. **Конфиг** `~/.config/opencode/opencode.jsonc` со всеми MCP и DeepSeek

## Принципы разработки

- **Нулевой порог входа**: одна команда, один вопрос (ключ DeepSeek), всё остальное автоматически.
- **Идемпотентность**: повторный запуск установщика не ломает систему, а обновляет компоненты.
- **Проверки перед установкой**: если компонент уже есть — пропустить, а не ставить заново.
- **Понятные ошибки**: если что-то не так (нет Firefox, нет Java, нет интернета) — написать ЧТО и КАК исправить, а не просто «error».
- **Кроссплатформенность**: macOS + Linux напрямую, Windows через WSL2 (нативный Windows — не поддерживаем в v1).
- **Не трогать чужие файлы**: всё в `~/.config/opencode/` и `~/.local/share/legal-agent/`.

## Стек

- **Язык установщика**: Bash (POSIX-совместимый, но с `set -euo pipefail`)
- **MCP-сервер `sudrf-scraper-mcp`**: Python 3.11+ с FastMCP
- **Проверки**: `command -v`, `test -f`, `curl --fail`
- **Логи**: цветной вывод (`\033[0;32m` для успеха, `\033[0;31m` для ошибок)

## Запрещено

- ❌ Устанавливать что-либо через `sudo` без явного согласия пользователя
- ❌ Скачивать бинарники без проверки контрольной суммы (где возможно)
- ❌ Писать секреты (ключи API) в логи или stdout
- ❌ Использовать платные сервисы (atomno-mcp-sudact, api-parser) — **только бесплатные**
- ❌ Перезаписывать существующий `opencode.jsonc` без бэкапа (`.bak`)

## Правила работы с DeepSeek API Key

1. Спросить у пользователя: `read -s -p "Вставьте DeepSeek API Key: " DEEPSEEK_KEY`
2. **Не эхоить** ключ в терминал (флаг `-s`)
3. Записать в `opencode.jsonc` через `sed` (не через `echo >>`)
4. Никогда не логировать ключ
5. Если пользователь не ввёл ключ — предложить два варианта:
   - Ввести сейчас
   - Пропустить и ввести позже через `opencode /connect` (но тогда MCP не заработают)

## Конвенции по коду

- Функции: `check_command()`, `install_node()`, `write_config()`
- Переменные: `UPPER_CASE` для констант, `lower_case` для локальных
- Каждый шаг — отдельная функция с `echo "▸ Шаг N: ..."`
- Финальный вывод: чек-лист «что установлено / что работает / что дальше»
