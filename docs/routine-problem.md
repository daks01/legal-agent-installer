# Проблема рутины: что именно автоматизируем

## Определение рутины

**Рутина** — это повторяющиеся действия, которые:
1. Занимают время, но не требуют юридического мышления.
2. Выполняются по одному и тому же алгоритму.
3. Могут быть описаны как «если X, то сделай Y».

Юридическое мышление (оценка рисков, стратегия, переговоры) — **не рутина**.
Её мы не автоматизируем.

## Три категории рутины

### Категория 1: Поиск и сверка норм

**Что делает юрист вручную**:
- Открывает КонсультантПлюс.
- Ищет статью по ключевым словам.
- Проверяет, действует ли редакция.
- Копирует текст в документ.
- Сверяет номер статьи и её содержание.

**Почему это рутина**: алгоритм одинаковый, результат предсказуем.

**Что должен делать агент**:
- Найти норму через `ru-legal-mcp`.
- Проверить цитату через `validate_citation`.
- Проверить актуальность через `check_currency`.
- Вставить в документ **со ссылкой на источник**.

**Критерий успеха**: агент никогда не вставляет норму, если `validate_citation` вернул «не найдено».

### Категория 2: Поиск судебной практики

**Что делает юрист вручную**:
- Открывает `sudact.ru` или `kad.arbitr.ru`.
- Вводит ключевые слова.
- Просматривает десятки решений.
- Отбирает релевантные.
- Копирует цитаты.

**Почему это рутина**: поиск по ключевым словам, фильтрация по датам/судам.

**Что должен делать агент**:
- Запустить `run_sudrf_scrape(query, date_from, limit)`.
- Дождаться результата.
- Прочитать JSON, сгруппировать по позициям судов.
- Выдать выжимку с цитатами.

**Критерий успеха**: агент возвращает выжимку **с указанием источника** (URL решения), а не пересказ «по памяти».

### Категория 3: Заполнение шаблонов

**Что делает юрист вручную**:
- Открывает прошлый документ.
- Копирует структуру.
- Заменяет реквизиты, суммы, даты.
- Проверяет, что все поля заполнены.

**Почему это рутина**: структура повторяется, меняются только данные.

**Что должен делать агент**:
- Прочитать шаблон `.docx` через `office-docs-mcp`.
- Заполнить плейсхолдеры `{{...}}` данными.
- Сохранить новый файл.
- Проверить, что не осталось незаполненных `{{...}}`.

**Критерий успеха**: агент сохраняет `.docx` **с сохранением форматирования** шаблона.

## Что НЕ автоматизируем

| Задача | Почему не автоматизируем |
|---|---|
| Оценка судебной перспективы | Требует юридического мышления |
| Стратегия ведения дела | Требует контекста, которого нет у агента |
| Переговоры с контрагентом | Требует живого общения |
| Подписание документов | Юридическая ответственность |
| Финальная проверка документа | Ответственность лежит на юристе |

## Метрики рутины

| Метрика | Как есть | Как должно быть |
|---|---|---|
| Время на поиск норм | 30–60 мин | 2–5 мин (проверка результата) |
| Время на поиск практики | 1–2 часа | 10–15 мин (проверка выжимки) |
| Время на заполнение шаблона | 30–60 мин | 5 мин (проверка + правки) |
| Риск сослаться на несуществующую норму | Средний | Минимальный (validate_citation) |
| Риск забыть заполнить поле | Средний | Минимальный (проверка `{{...}}`) |

## Принцип «не навреди»

Агент **не принимает юридических решений**. Он **готовит черновик**, который юрист проверяет.
Если агент не уверен — он **обязан** написать `[НЕ НАЙДЕНО]`, а не выдумывать.
