# Требования для приёмки решения

## Формат приёмки

Каждый критерий проверяется **на чистой машине** (macOS или Ubuntu в WSL),
где предварительно **не установлен** ни OpenCode, ни Python-зависимости.

## A. Установка (Installation)

| # | Критерий | Как проверить |
|---|---|---|
| A1 | Установка одной командой | `curl -fsSL .../install.sh \| bash` |
| A2 | Запрос DeepSeek API Key | Скрипт спрашивает ключ, не эхоит его |
| A3 | Установка < 15 минут | Замер времени на чистой машине |
| A4 | Нет ошибок в выводе | `grep -i error install.log` пусто |
| A5 | Идемпотентность | Повторный запуск не ломает систему |
| A6 | Бэкап конфига | Если `opencode.jsonc` был — создан `.bak` |
| A7 | Понятные ошибки | Если нет Firefox — сообщение «установите Firefox» |
| A8 | Работает на macOS | Проверено на macOS 14+ |
| A9 | Работает на Ubuntu (WSL) | Проверено на Ubuntu 22.04+ |
| A10 | PowerShell-обёртка для Windows | `install.ps1` запускает `install.sh` в WSL |

## B. Конфигурация OpenCode

| # | Критерий | Как проверить |
|---|---|---|
| B1 | DeepSeek прописан в конфиге | `cat ~/.config/opencode/opencode.jsonc \| grep deepseek` |
| B2 | Ключ не в логах | `grep -r "sk-" ~/.config/opencode/` находит только конфиг |
| B3 | MCP `ru-legal` доступен | `opencode mcp list \| grep ru-legal` |
| B4 | MCP `office-docs` доступен | `opencode mcp list \| grep office-docs` |
| B5 | MCP `sudrf-scraper` доступен | `opencode mcp list \| grep sudrf-scraper` |
| B6 | Скилл `source-locked-ru` установлен | `ls ~/.config/opencode/skills/source-locked-ru/SKILL.md` |

## C. Работа с Word

| # | Критерий | Как проверить |
|---|---|---|
| C1 | Агент читает `.docx` | Положить файл в `~/knowledge_base/`, попросить прочитать |
| C2 | Агент заполняет шаблон | Шаблон с `{{name}}`, попросить заполнить |
| C3 | Форматирование сохраняется | Открыть результат в Word — стили на месте |
| C4 | Незаполненные поля видны | Если данных нет — агент пишет `[НЕ НАЙДЕНО]`, не выдумывает |
| C5 | Агент сохраняет новый файл | Файл появляется в `~/knowledge_base/output/` |

## D. Работа с законами (защита от галлюцинаций)

| # | Критерий | Как проверить |
|---|---|---|
| D1 | Агент ищет норму через MCP | Спросить «что говорит ст. 333 ГК РФ» → в ответе есть цитата |
| D2 | Цитата валидируется | `validate_citation` возвращает `valid: true` |
| D3 | Несуществующая норма | Спросить «что говорит ст. 99999 ГК РФ» → агент пишет `[НЕ НАЙДЕНО]` |
| D4 | Устаревшая норма | Спросить про отменённую статью → агент предупреждает |
| D5 | Агент не выдумывает номера | Все ссылки в ответе имеют источник из MCP |
| D6 | Скилл `source-locked-ru` работает | Если источник не найден — ответ «не найдено», не догадка |

## E. Работа с судебной практикой

| # | Критерий | Как проверить |
|---|---|---|
| E1 | Агент запускает скрапер | Попросить «найди практику по ст. 333 ГК РФ» → агент вызывает `run_sudrf_scrape` |
| E2 | Скрапер возвращает JSON | Файл появляется в `~/knowledge_base/court_practice/` |
| E3 | Агент читает JSON | Агент анализирует файл, а не выдумывает |
| E4 | Агент указывает источник | В выжимке есть URL решений или ID дел |
| E5 | Таймаут не ломает агента | Если скрапер идёт > 5 мин, агент сообщает «в процессе» |
| E6 | Капча не блокирует | Если капча — агент сообщает «требуется ручной ввод» (v1) |

## F. Telegram-бот (опционально)

| # | Критерий | Как проверить |
|---|---|---|
| F1 | Бот отвечает только владельцу | Whitelist по user ID |
| F2 | Бот принимает файлы | Отправить `.docx` → агент его видит |
| F3 | Бот отправляет файлы | Агент создаёт `.docx` → файл приходит в Telegram |
| F4 | Команда `/new` создаёт сессию | История очищается |
| F5 | Команда `/models` показывает модели | Список доступных моделей |

## G. Документация

| # | Критерий | Как проверить |
|---|---|---|
| G1 | README понятен неразработчику | Дать прочитать юристу без техбэкграунда |
| G2 | Есть примеры промптов | В README 5+ примеров |
| G3 | Есть FAQ | 5+ типовых проблем и решений |
| G4 | Есть инструкция по удалению | `uninstall.sh` удаляет всё без следов |

## H. Нефункциональные требования

| # | Критерий | Как проверить |
|---|---|---|
| H1 | Стоимость < $5/мес | Замер токенов за типовую неделю |
| H2 | Работает без интернета (кроме API) | Отключить сеть → агент сообщает об ошибке, не падает |
| H3 | Конфиденциальность | Ключ DeepSeek не уходит третьим лицам |
| H4 | Логи не содержат ПДн | `grep` по логам на ФИО, ИНН, адреса |

## I. Критерии «НЕ приёмка»

Решение **не принимается**, если:

- ❌ Агент выдумывает нормы, которых нет в MCP.
- ❌ Агент вставляет `{{...}}` в готовый документ (незаполненные поля).
- ❌ Форматирование шаблона ломается после заполнения.
- ❌ Установка требует ручного редактирования конфигов.
- ❌ Ключ DeepSeek попадает в логи или stdout.
- ❌ Скрапер запускается без ведома пользователя (без явной команды).
- ❌ Агент даёт юридические советы («я считаю, что суд решит...»).
