# Пользовательский сценарий: юрист с рутинными задачами

## Кто пользователь

Частнопрактикующий юрист или юрист в небольшой фирме (1–5 человек).
Не программист. Работает в Word и Excel. Иногда — с судебной практикой.
Имеет лицензионный КонсультантПлюс. Хочет автоматизировать рутину,
но не готов тратить часы на настройку инструментов.

## Контекст работы

- **Документы**: договоры, претензии, исковые заявления, процессуальные документы.
- **Формат**: `.docx` (основной), `.xlsx` (расчёты, реже).
- **Источники права**: КонсультантПлюс (лицензия), иногда — судебная практика.
- **Устройство**: домашний компьютер или рабочий ноутбук. Иногда — доступ с телефона.
- **Время**: юрист занят, не готов разбираться в терминах и конфигах.

## Типичный день (как есть сейчас)

1. **Утро**: приходит задача — составить исковое заявление о взыскании долга.
2. Юрист открывает прошлый похожий иск в Word, копирует структуру.
3. Ищет в КонсультантПлюс актуальные статьи ГК РФ, вставляет вручную.
4. Ищет судебную практику по аналогичным делам — вручную, через браузер.
5. Заполняет реквизиты, суммы, расчёты (иногда — в Excel).
6. Проверяет, что все ссылки на законы актуальны.
7. Отправляет документ.

**Время**: 2–4 часа на один документ. Из них **60–70% — рутина**:
поиск, копирование, сверка, форматирование.

## Целевой сценарий (как должно быть)

1. **Утро**: та же задача — исковое заявление.
2. Юрист открывает агента (OpenCode GUI или Telegram).
3. Пишет: «Составь исковое о взыскании долга по договору поставки №X.
   Используй шаблон `templates/claim-template.docx`. Данные: [файл с реквизитами].»
4. **Агент**:
   - Читает шаблон `.docx` через MCP.
   - Находит релевантные статьи ГК РФ через `ru-legal-mcp` (с проверкой цитат).
   - Ищет судебную практику через `sudrf-scraper-mcp` (если нужно).
   - Заполняет шаблон, сохраняет новый `.docx`.
   - Возвращает юристу **готовый файл + список использованных норм с указанием источника**.
5. Юрист **проверяет** документ (5–10 минут), вносит правки, отправляет.

**Время**: 30–40 минут вместо 2–4 часов.

## Ключевые боли, которые решает агент

| Боль | Как решает |
|---|---|
| Ручной поиск статей в КонсультантПлюс | `ru-legal-mcp` + `validate_citation` |
| Ручной поиск судебной практики | `sudrf-scraper-mcp` (автономный скрапинг) |
| Копирование структуры из прошлых документов | `office-docs-mcp` читает `.docx`-шаблоны |
| Риск сослаться на устаревшую или несуществующую норму | `source-locked-ru` + `validate_citation` |
| Невозможность работать с телефона | Telegram-бот (опционально) |
| Страх «ИИ выдумает закон» | Протокол «не найдено — так и скажи» |

## Что НЕ входит в сценарий v1

- Полная автоматизация документооборота (только генерация по шаблону).
- Интеграция с 1С, CRM, ЭДО.
- Замена КонсультантПлюс (он остаётся источником истины для ручной проверки).
- Юридическая ответственность (все документы проверяет юрист).
