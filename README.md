# Legal Agent Installer

Установщик ИИ-агента для юридической фирмы «из коробки» — на базе [OpenCode](https://opencode.ai).

## Что это

Одна команда разворачивает готовое к работе место юриста:

- **OpenCode** — ИИ-агент в терминале
- **DeepSeek** — языковая модель (понадобится свой API-ключ DeepSeek)
- **MCP-серверы** — законы РФ и судебная практика, чтение и запись Word/Excel, сбор дел с sudrf.ru
- **Скилл `source-locked-ru`** — агент отвечает строго по источникам, без выдумок
- **Папка `~/knowledge_base/`** — сюда складываются ваши документы, которые видит агент

## Для кого

Для юристов, которые не программируют. Всё, что нужно уметь, — скопировать одну команду
в терминал и вставить API-ключ.
