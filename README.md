# Legal Agent — ИИ-помощник для юриста

Установщик разворачивает готовое рабочее место: **OpenCode** (агент) + **DeepSeek**
(модель) + инструменты для работы с документами, законами РФ, судебной практикой
и контрагентами — «из коробки», без настройки.

Пользователь — юрист, а не программист: одна команда, один вопрос (ключ DeepSeek),
дальше всё само.

## Что умеет агент

| Задача | Инструмент внутри |
| --- | --- |
| Прочитать/заполнить Word и Excel | `office-docs` MCP (`.docx`, `.xlsx`) |
| Найти норму РФ с цитатой и источником | `pravo` MCP (pravo.gov.ru) + скиллы `ru-legal` |
| **Точный текст статьи кодекса** (ГК, УК, НК…) | `laws` MCP — локальная база (SQLite, без интернета) |
| **Письма Минфина/ФНС с текстом** | `laws` MCP (13 444 разъяснения) |
| **Проверка официального опубликования** | `laws` MCP — публикации pravo.gov.ru (~опционально) |
| Найти судебную практику судов общей юрисдикции | `sudrf-scraper` (наше приложение) |
| Найти арбитражную практику | `kad` MCP (kad.arbitr.ru) |
| Проверить контрагента (ЕГРЮЛ/ЕГРИП) | `egrul` MCP (api-fns.ru, бесплатный тариф) |
| Работать «только по источникам» | скилл `source-locked-ru`: не выдумывает, пишет `[НЕ НАЙДЕНО]` |
| Работать в привычном окне (GUI) | OpenCode Desktop — устанавливается автоматически (можно пропустить: `--no-desktop`) |
| Готовые юридические сценарии (договоры, кадры, налоги…) | 145 скиллов `ru-legal` |

Агент **не даёт юридических советов** и не принимает решений — он готовит черновик,
который проверяет юрист.

## Требования

- **macOS 12+** или **Linux (Ubuntu 22.04+, в т.ч. WSL2)**, либо
  **Windows 10 (1809+)/Windows 11 — нативно** (без WSL) или через WSL2.
  ❌ **Windows 7/8 не поддерживается** (WSL2 там не существует): обновите ОС
  или поставьте агента на одну машину с Win10/11 и работайте с неё.
- Интернет и **ключ DeepSeek** (получить: https://platform.deepseek.com/api_keys).
- Для судебной практики: браузер **Firefox** и **российский IP**
  (часть сайтов судов блокирует зарубежные адреса).
- Для проверки контрагентов (опционально): бесплатный ключ api-fns.ru.

## Установка

**Одна команда** (macOS, Linux, Windows через WSL):

```bash
curl -fsSL https://raw.githubusercontent.com/daks01/legal-agent-installer/main/install.sh | bash
```

Дополнительно: `... | bash -s -- --with-publications` — добавить базу официальных
публикаций pravo.gov.ru (~160 МБ).

Альтернатива — из клонированного репозитория:

```bash
git clone https://github.com/daks01/legal-agent-installer
cd legal-agent-installer
bash install.sh
```

**Windows 10/11 — нативно, без WSL** (одна команда PowerShell):

```powershell
irm https://raw.githubusercontent.com/daks01/legal-agent-installer/main/setup-windows.ps1 -OutFile "$env:TEMP\setup-windows.ps1"
powershell -ExecutionPolicy Bypass -File "$env:TEMP\setup-windows.ps1"
```

Установщик также поставит **OpenCode Desktop** (GUI-приложение: меню Пуск →
OpenCode). Не нужно — добавьте `-NoDesktop`.

Подробно (включая установку самого opencode и вопрос про Windows 7) —
`docs/windows-manual.md`. Enterprise-вариант через WSL2: `install.ps1` из
клонированного репозитория.

Установщик спросит ключ DeepSeek (можно пропустить и вставить позже).
Диагностика без установки: `install.ps1 -Doctor` (Windows) или
`bash tests/test_install.sh` (после установки).

## Примеры промптов

1. **Проверка договора**
   «Прочитай `~/knowledge_base/templates/договор-поставки.docx` и дай список
   рисков со ссылками на нормы ГК РФ. Где нет источника — пиши [НЕ НАЙДЕНО].»
2. **Заполнение шаблона**
   «Заполни шаблон `~/knowledge_base/templates/доверенность.docx`:
   ФИО — Иванов Иван Иванович, паспорт — 45 12 345678, ООО "Пример".
   Сохрани в `~/knowledge_base/output/` и покажи, что заменено.»
3. **Судебная практика**
   «Найди практику по ст. 333 ГК РФ: Москва, районные суды, 2024 год.
   Дай выжимку с номерами дел и ссылками.»
4. **Проверка контрагента**
   «Проверь ООО "Ромашка" по ИНН 7707083893: статус, руководитель,
   признаки проблемности. Укажи дату проверки.»
5. **Норма с источником**
   «Что говорит ст. 333 ГК РФ? Дай точную цитату и источник. Если не
   подтверждается — [НЕ НАЙДЕНО].»
6. **Проект претензии**
   «Подготовь проект претензии о взыскании долга по договору поставки №12/2026,
   данные: ... Используй шаблон `~/knowledge_base/templates/претензия.docx`.»

## Где лежат документы

```
~/knowledge_base/
├── templates/       # ваши шаблоны .docx (агент заполняет их)
├── consultant/      # выгрузки из КонсультантПлюс
├── court_practice/  # результаты сбора судебной практики (JSON)
└── output/          # готовые документы от агента
```

## Обновление и удаление

- **Обновление**: повторный запуск `bash install.sh` (не ломает систему, обновляет
  компоненты). Для переустановки sudrfscraper: `FORCE=1 bash install.sh`.
- **Удаление**: `bash uninstall.sh` — убирает всё, что поставил установщик.
  Ваши документы сохраняются; удалить и их: `bash uninstall.sh --purge-docs`.

## Если что-то пошло не так (FAQ)

1. **«Агент просит ключ / не отвечает»** — вставьте ключ DeepSeek в
   `~/.config/opencode/opencode.jsonc` (поле `apiKey`), затем перезапустите
   `opencode`. Ключ: https://platform.deepseek.com/api_keys
2. **«MCP-серверы не подключаются»** — выполните `opencode mcp list`. Если пусто:
   проверьте, что `~/.local/bin` есть в PATH (`uvx` должен находиться),
   и перезапустите терминал.
3. **«Сбор практики: Server error / ноль дел»** — почти всегда **VPN или
   зарубежный IP**. Отключите VPN (или исключите `*.sudrf.ru` из туннеля)
   и запустите сбор заново. Также проверьте, что установлен Firefox.
4. **«Сбор встал и ничего не происходит»** — вероятно, сайт суда показывает
   **капчу**: откройте http://localhost:8080 в браузере и введите капчу
   (так задумано — авторешение капчи отключено).
5. **«Windows 7»** — не поддерживается. Варианты: обновить ОС до Windows 10/11,
   либо поставить агента на одну машину с Win10/11 в фирме.
6. **«Windows 10, установщик просит WSL»** — обновите Windows до 22H2 и выполните
   инструкции установщика; на старых ПК может понадобиться включить виртуализацию
   (VT-x/AMD-V) в BIOS: `install.ps1 -Doctor` подскажет.
7. **«Хочу начать заново»** — `bash uninstall.sh`, затем `bash install.sh`.
8. **«База законов устарела / как обновить?»** — локальная база (`laws`) — это
   снапшот официальных текстов. Обновление: `bash update-laws.sh` (качает новую
   версию из релиза; без Docker и интернета во время работы). Посмотреть дату
   снапшота: спросите агента «проверь статус базы законов».
9. **«Нужны официальные публикации (1,1 млн актов pravo.gov.ru)?»** —
   установите с `bash install.sh --with-publications` (или
   `bash update-laws.sh --with-publications`, ≈160 МБ).
10. **«Куда попадают мои документы?»** — документы, которые агент читает,
   отправляются в DeepSeek API (это языковая модель, без неё агент не работает).
   Иных третьих лиц нет: законы, практика и контрагенты запрашиваются напрямую
   с официальных источников. Ключи хранятся только у вас на компьютере.

## Для разработчиков

- Правила и архитектура: `AGENTS.md`
- План и история: `plan.md`, `NOTES.md`
- Критерии приёмки: `docs/acceptance-criteria.md`

Решения принимаются «только по источникам»: агент не выдумывает нормы и практику,
не даёт юридических советов и всегда указывает `[НЕ НАЙДЕНО]`, если подтверждения нет.
