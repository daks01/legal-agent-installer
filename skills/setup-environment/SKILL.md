# Setup Environment — самостоятельная настройка окружения

Ты настраиваешь рабочее окружение юриста «с нуля» или чинишь/обновляешь его.
Пользователь — не разработчик: все команды выполняешь ты (или даёшь ему одну
готовую строку для вставки), а ключи он вводит сам в защищённом приглашении.

## Что должно получиться

- OpenCode с DeepSeek (ключ пользователя) и MCP-серверами:
  `ru-legal`, `pravo`, `kad`, `egrul` (опц.), `laws`, `office-docs`, `sudrf-scraper`
- Скиллы `source-locked-ru` и `setup-environment` в `~/.config/opencode/skills/`
- Локальная база законов (`laws.db`) + папка `~/knowledge_base/`

## Порядок действий по ОС

### 1. Определи ОС

- macOS / Linux / WSL → шаг 2a
- Windows (нативный, без WSL) → шаг 2b
- Windows 7/8/8.1 → шаг 2c

### 2a. macOS / Linux / WSL

Выполни (одна команда — установщик сделает всё сам):

```bash
curl -fsSL https://raw.githubusercontent.com/daks01/legal-agent-installer/main/install.sh | bash
```

- Скрипт сам спросит **DeepSeek API Key** (и опционально api-fns) в защищённом
  режиме — пользователь вводит их в терминале, в чат они не попадают.
- После завершения: **перезапустите opencode** (конфиг читается при старте).

Для повторного обновления: та же команда. Только база законов:
`bash update-laws.sh` (из папки установщика).

### 2b. Windows 10 (сборка 1809+) / Windows 11 — нативно, без WSL

1. Убедись, что opencode установлен (`Get-Command opencode`). Если нет — скажи
   пользователю поставить opencode (см. `docs/windows-manual.md`, шаг 1), это
   единственное, что нужно сделать вручную.
2. Запусти установочный скрипт (скачает и выполнит; спросит ключи у
   пользователя защищённо):

```powershell
$s = "$env:TEMP\setup-windows.ps1"; irm https://raw.githubusercontent.com/daks01/legal-agent-installer/main/setup-windows.ps1 -OutFile $s; powershell -ExecutionPolicy Bypass -File $s
```

   Если у тебя (агента) нет доступа к PowerShell — дай пользователю эту строку
   целиком для вставки в PowerShell.
3. После завершения: **перезапустите opencode**.

Повторный запуск того же скрипта = обновление (идемпотентен).

### 2c. Windows 7 / 8 / 8.1

Нативно **не поддерживается**: opencode (Bun) и uv требуют Windows 10 1809+.
Не пытайся ставить — объясни пользователю варианты:

- обновить ОС до Windows 10 (22H2) / 11;
- либо поставить агента на одну машину с Win10+/Linux в фирме и работать с неё;
- либо удалённый доступ к такой машине (например, через `opencode web` —
  агент запущен на Win10-машине, а с Win7 открывается веб-интерфейс в браузере;
  пометьте как экспериментальный вариант для старого браузера).

## Проверка после перезапуска

Попроси пользователя (или проверь сам в новой сессии):

```
opencode mcp list            → 6 connected + egrul disabled (если без ключа api-fns), laws connected
```

и вопрос агенту: «проверь статус базы законов» → `laws_status` покажет снапшот.

## Важные правила

- **Ключи** вводит пользователь в защищённом приглашении (`read -s` /
  `Read-Host -AsSecureString`) — не проси присылать их в чат и не логируй.
- DeepSeek-ключ обязателен (https://platform.deepseek.com/api_keys);
  api-fns — опционален (бесплатный тариф, ~100 запросов/метод).
- Конфиг перечитывается только при старте — **перезапуск opencode обязателен**.
- Windows 10: если нет прав запускать PowerShell-скрипты — предложи
  `-ExecutionPolicy Bypass` (указан в команде выше).
- Если установка упала — не импровизируй: покажи пользователю лог
  (`install.log` рядом с запуском / вывод скрипта) и предложи прислать его.
